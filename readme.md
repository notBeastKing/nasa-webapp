# Interactive Planetary Orrery Nasa webapps challenge

This was the **first website** created by me and my friends, built for a **NASA-hosted hackathon**.  
The **landing page** was made by me — it features an animated **orrery** displaying all the planets with clickable info for each.

We kept it simple and focused on creativity using just:

- **HTML**
- **CSS**
- **JavaScript**
- Some enhancements inspired by **CodePen** (like custom cursors and effects)

---

## Features

- A dynamic **orrery** showing the planets of the solar system
- Clickable celestial bodies that reveal basic planetary data
- Eye-catching visual effects for a fun, educational experience

---

## How to Run

To view the website locally:

1. Make sure you have [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) or [Five Server](https://marketplace.visualstudio.com/items?itemName=yandeu.five-server) installed as a VS Code extension
2. Open the root project folder in VS Code
3. Right-click on `main.html` → Click **"Open with Live Server"** or **"Five Server: Open with Live Preview"**

The webpage should launch in your browser!
